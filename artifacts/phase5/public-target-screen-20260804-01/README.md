# Public mtk-su target screen

Host-only source review of historical Fire tablet rooting material. This
artifact contains no exploit payload and no device output.

The historical page explicitly separates its Fire HD 10 2017 tested target
from a Fire HD 10 2019 / Fire OS 7.3.1.0 untested target, and warns that the
remaining instructions are mainly for the 2017 device. This is not evidence
for the 2021 KFTRWI/PS7330 target.
